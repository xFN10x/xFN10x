<h2 align="center">
An addon for create that adds stealth & survaliance to your Minecraft world!
</h2>

Create: Stealth & Security adds new redstone components, and game mechanics to let you make the best Minecraft prison
possible, like;

- **The Sight Sensor**: Detects when Entites are looking at it. (Ponder included, advanced version planned.)
- **The Laser Diode**: Detects when a laser is disturbed. Wrench a laser diode to create a laser optic to detect a
  laser. (Ponder next release, advanced version planned)
- **Fini-Goggles**: Goggles that let you see invisible entities.

This mod also adds invisible player name obfuscation, which makes invisible player's names not appear in death
messages. (Configurable in the config.)
